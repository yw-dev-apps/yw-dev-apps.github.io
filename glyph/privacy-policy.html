プライバシーポリシー

GLYPH（表示名: GLYPH / Bundle ID: app.glyph）

最終更新日: 2026年8月10日

1. はじめに

本アプリは、世界の文字をガチャで集めるコレクションアプリです。運営者の独自サーバーは持ちません。無料利用時は第三者広告（後述）を表示することがあり、その場合は広告配信事業者のサービスが技術情報を処理することがあります。

2. 端末内に保存されるデータ

本アプリはアカウント登録を必要としません。ゲーム進行データは端末内に保存され、運営者の独自サーバーへ送信しません（広告配信については「4. 広告」を参照）。

データ用途保存場所
所持ポイント・図鑑（獲得文字）・ガチャ回数・お気に入り・バイブ／効果音設定・無料チャージ日時など機能提供・進行の継続端末内（UserDefaults）
購入状態（ポイントパック・広告削除）付与・広告非表示App Store / StoreKit の購入情報（端末・Apple アカウント側）。処理済み取引 ID の一部は端末内にも記録

3. 広告

広告削除を購入していない場合、アプリ内にバナー広告を表示することがあります。ポイント不足時やチャージのため、リワード広告（視聴完了でポイント付与）を利用できます。広告削除購入後も、リワード広告によるポイント獲得は利用できます。

  • 広告配信にはGoogle AdMob（Google Mobile Ads SDK）を使用します
  • アプリの PrivacyInfo.xcprivacy では、広告表示に伴い端末識別子・広告データが第三者広告目的で処理されうることを宣言します（ATT によるトラッキングは行いません）。Google Mobile Ads SDK 同梱のプライバシーマニフェストも合わせて App Privacy Report に集約されます
  • 表示位置の例: ホーム・チャージ・ガチャ結果のバナー、およびリワード広告
  • 広告の表示・配信のため、Google の SDK が端末に関する技術情報（例: IP アドレス、端末情報、広告に関する識別子など）を取得・処理する場合があります。詳細はGoogle のプライバシーポリシーおよびGoogle の広告に関する説明を参照してください
  • 運営者が、広告を通じて取得した情報を販売することはありません

4. 外部送信・トラッキング

  • 本アプリから運営者の独自サーバーへ、ゲーム進行データを送信しません
  • App Store の購入処理（ポイントパック・広告削除）はApple のサービスが提供します
  • 広告配信のため、上記「3. 広告」のとおりGoogle のサービスへ技術情報が送信される場合があります
  • 文字詳細の「調べる」は、ユーザー操作により端末のブラウザ等で Google 検索を開きます（運営者のサーバーは経由しません）
  • 運営者は、ユーザーを他社のアプリやウェブサイトを横断して追跡する目的でのトラッキング（App Tracking Transparency で求められる種類の追跡）を行いません
  • 運営者独自の解析（アナリティクス）SDK は使用しません

5. データの削除

  • アプリ内のリセット操作で、図鑑・お気に入り・ガチャ回数などを消去できます（所持ポイント・広告削除は残ります）
  • アプリを端末から削除すると、原則として当該端末に保存された本アプリのデータも削除されます

6. お子様

本アプリは特定の年齢を対象としていませんが、13歳未満の方が利用する場合は保護者の同意のもとでご利用ください。

7. ポリシーの変更

本ポリシーを変更する場合、本ページの更新日を改め、必要に応じてアプリ内で告知します。

8. お問い合わせ

連絡先: yw.dev.support+glyph@gmail.com（YW Dev Support）
